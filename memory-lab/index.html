Как читать результат

Одна находка – три проверки

Например, ученик сначала ошибся, а затем исправился после подсказки. Один правильный ответ в отрыве от предыдущих реплик может создать ложное впечатление о самостоятельности.

  1. ВопросЧто помогло исправить ошибку?
  2. Найденный фрагментРядом находятся ошибка, подсказка и исправление.
  3. Проверка человекомПосмотрите исходные реплики и условия, прежде чем делать вывод.

Для любопытных

Что здесь используется

Несколько контуров решают разные задачи. Наличие компонента в коде не означает, что он сейчас развёрнут.

01 / Эта страница

Браузерная демонстрация

HTML, CSS и JavaScript на GitHub Pages. Transformers.js и multilingual-e5-small запускают поиск по смыслу в браузере. Загрузка модели идёт из Hugging Face и jsDelivr; запросы не отправляются на сервер модели.

Это отдельная реализация, не тест реальной базы «Алёны».

02 / Локальный прототип

Данные и модель

Python/FastAPI, PostgreSQL с pgvector и Ollama. В локальной конфигурации используются Gemma и BGE-M3; реализован гибридный поиск по разрешённым источникам.

Фактическая доступность зависит от запуска и настройки локальных сервисов.

03 / Исследование

Альтернативные подходы

Graphiti хранит связи, Mem0 формирует текстовые кандидаты памяти, LangGraph управляет шагами поиска. Эти варианты исследовались отдельно; графовый путь в приложении экспериментальный.

Синтетические исследования и автоматические оценки не доказывают готовности к работе с детьми.
